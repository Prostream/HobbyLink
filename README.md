## Project Description
HobbyLink investigates how people organize and participate in small group activities around shared interests, such as board games, hiking, and recreational sports. The project focuses on understanding activity discovery, attendance coordination, and communication challenges.

## Current Phase
**Phase 1: Research & Planning**

Current work covers background research, competitor analysis, stakeholder identification, design thinking milestones, and conceptual technical planning.
